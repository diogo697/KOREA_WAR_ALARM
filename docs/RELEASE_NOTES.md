# Korea War Alarm 0.1.0

공개 피드 기반 개인용 로컬 모니터 배포본.
별도 가입·결제·외부 API 키 없이 기본 4개 소스를 수집한다.

- ZIP 압축을 풀고 `kwa/kwa.exe`(Windows) 또는 `kwa/kwa`(macOS/Linux)를 실행한다.
- 최초 실행 시 사용자 데이터 폴더에 설정을 생성하고 로컬 화면을 연다.
- REST/SSE/WebSocket·CLI·desktop 알림·webhook·선택 MQTT를 포함한다.
- checksum 파일로 ZIP의 SHA-256을 확인할 수 있다.

피드의 게시 지연·원출처 확인 한계가 있으며 실제 전쟁 탐지의 정확도나 속도를 보장하지 않는다.
원출처 불명 보도를 독립 증거로 올리지 않는다. 기본 콘텐츠는 비상업 로컬 열람용이며 원문 권리는 제공자에게 있다.
코드 서명/공증되지 않은 빌드에는 OS 실행 안내가 표시될 수 있다.
