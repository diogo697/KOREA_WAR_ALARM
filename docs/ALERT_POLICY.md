# 판정 정책

출처별 신뢰도는 초기 정책 값이며 통계적으로 보정된 전쟁 발생 확률이 아니다.
LLM을 사용하지 않는다. Core만 최종 상태를 계산한다.

1. UTC timestamp·텍스트·URL을 정규화한다. 한국 정부 직접 소스는 설정에서 제외한다.
2. 동일 source+canonical URL+제목은 저장 중복을 차단한다. 유사 보도는 보존하되 동일 원출처·publisher·제목은 독립 증거로 중복 계산하지 않는다.
3. 출처가 명시한 사건 시각(없으면 발행 시각) 차이 180초 이내, 호환 category, 좌표 100km 이내 또는 동일 구체 지명으로 사건을 묶는다. 발행 시각을 실제 발생 시각으로 주장하지 않는다. 한반도라는 넓은 지역만 일치하면 병합하지 않는다.
4. 한국 정부 재인용·원출처 미확인·발행시각 누락/미래 오류·15분 이상 지난 근거·한반도와 무관한 근거는 점수에서 제외한다.
5. 독립 계열별 가장 높은 신뢰도 근거를 사용한다.

RSS의 한국 지명 단순 언급은 사건 발생 장소로 취급하지 않는다. 공격과 장소를 직접 연결하는 제한된 제목 문형만 인정하고 외교 논평은 제외한다. 서울·평양·연평도는 도시 중심점을 근접 비교에 사용하며 metadata에 `location_precision=city_centroid`를 남긴다. 이는 공격의 정확한 좌표나 지진과 공격의 인과관계를 보장하지 않는다. 지원하지 않는 표현은 미탐 가능성이 있다.

점수: `max_reliability * 0.55 + (family_count - 1) * 0.12 + physical_or_foreign_alert * 0.10 + relevant_evidence * 0.10 - contradiction * 0.40`, 0–0.99 제한.

| 레벨 | 최소 조건 |
|---|---|
| INFO | 유효한 관련 근거·최근 미확인 보도 없음 |
| WATCH | 유효 독립 근거 1개 이상 또는 15분 이내 원출처 미확인 관련 보도 |
| WARNING | 직접 군사행동/미사일/충돌 주장 + 독립 2계열 + 점수 ≥ 0.50 |
| HIGH | 위 조건 + 신뢰도 ≥ 0.8 해외 news/alert + 점수 ≥ 0.65 |
| CRITICAL | 직접 공격 + 독립 고신뢰 news/alert 2계열 + 총 3계열 이상 + 물리 센서/해외 경보 + 점수 ≥ 0.85 |

반증 metadata가 있으면 WATCH로 제한한다. 단일 OSINT·센서·뉴스 대량 복제만으로 CRITICAL을 만들지 않는다.
기본 구성은 고신뢰 뉴스 발행자 수가 부족해 CRITICAL·사이렌에 도달할 수 없다. `critical_capable=false` 및 경고로 이를 표시하며, 경보 문턱을 낮춰 우회하지 않는다.
사건은 마지막 유효 수집 후 기본 30분에 비활성화된다. 점수는 시간이 지나며 재평가된다.

최상위 사건이 canonical alert가 된다. 상태 변경마다 영속 `seq`가 증가한다.
동일 사건·동일 근거 반복은 알리지 않는다. 새 사건·새 독립 근거·레벨 상승은 즉시 다시 알린다.
그 밖의 상태 변경 재알림에는 기본 300초 cooldown을 적용한다.
로컬 알림과 webhook은 별도 영속 queue 및 별도 worker를 사용한다. 재시작 직전 처리 중이던 알림은 다시 전달될 수 있다.
Webhook 수신자는 `Idempotency-Key`를 저장해 중복을 방지한다.

한계: 현재 영문 제목 키워드 분류는 복잡한 부정·역사 회고·인용을 완전히 판별하지 못한다. 라이브 RSS의 독립성을 보수적으로 제외하여 HIGH/CRITICAL 오승격을 제한했다.
합성 CRITICAL 시나리오와 실제 USGS 2017 관측 사실 기반 fixture를 제공한다. 후자의 수신 시각은 재현용이며 실측이 아니다.
일반화 가능한 역사적 오탐률·미탐률 보정은 별도 과제다.
